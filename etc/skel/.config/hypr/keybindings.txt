APPS & SESSION
  SUPER + Return ............ terminal (alacritty)
  SUPER + T ................. terminal
  SUPER + Shift + Return .... file manager (thunar)
  SUPER + E ................. editor (code)
  SUPER + D / Space ........ app launcher (rofi drun)
  SUPER + Shift + D ......... run launcher (rofi run)
  SUPER + R / Alt + R ...... theme selector (rofi-theme-selector)
  SUPER + V ................. audio mixer (pavucontrol)
  SUPER + O ................. colour picker (hyprpicker)
  SUPER + X ................. logout dialog
  SUPER + Shift + E ......... logout dialog
  SUPER + Shift + X ......... power menu
  SUPER + Escape ........... kill mode (click a window to kill)
  SUPER + Ctrl + S .......... show these keybindings
  Ctrl + Alt + K ............ logout dialog (archlinux-logout)
  SUPER + Shift + R ......... reload Hyprland config

KIRO APPS  (Ctrl + Alt)
  Ctrl + Alt + A / Q ....... Alacritty Tweak Tool
  Ctrl + Alt + B ........... brave
  Ctrl + Alt + C ........... chromium
  Ctrl + Alt + D ........... OBS Studio
  Ctrl + Alt + E ........... Arch Linux Tweak Tool (ATT)
  Ctrl + Alt + H ........... Hyprland Tweak Tool
  Ctrl + Alt + I ........... Kiro ISO builder
  Ctrl + Alt + L ........... logout settings (archlinux-logout --settings)
  Ctrl + Alt + S ........... Fish Tweak Tool
  Ctrl + Alt + W / Z ....... Fastfetch Tweak Tool
  Ctrl + Alt + P ........... package manager (pamac)
  Ctrl + Alt + M ........... USB image writer (mintstick)
  Ctrl + Alt + R ........... lock screen (archlinux-betterlockscreen)
  Ctrl + Alt + U ........... audio mixer (pavucontrol)
  Ctrl + Alt + F ........... firefox
  Ctrl + Alt + G ........... chromium
  Ctrl + Alt + O ........... opera
  Ctrl + Alt + V ........... vivaldi
  Ctrl + Alt + Return / T .. terminal (alacritty)
  Ctrl + Alt + End ......... system monitor (btop)
  Ctrl + Shift + Escape .... system monitor (btop)

APP KEYS  (Super + Function keys)
  SUPER + F1 ............... firefox
  SUPER + F2 ............... editor (code)
  SUPER + F3 ............... inkscape
  SUPER + F4 ............... gimp
  SUPER + F5 ............... meld
  SUPER + F6 ............... vlc
  SUPER + F7 ............... virtualbox
  SUPER + F8 ............... file manager (thunar)
  SUPER + F9 ............... virt-manager
  SUPER + F10 .............. spotify
  SUPER + F11 / F12 ........ app launcher (rofi drun)

WINDOWS
  SUPER + Q / Shift + Q ..... close window
  SUPER + Shift + Space ..... toggle floating
  SUPER + F ................. fullscreen
  SUPER + Alt + F .......... maximize
  SUPER + P ................. pseudo-tile
  SUPER + J ................. toggle split direction
  SUPER + G ................. toggle group

MASTER LAYOUT
  SUPER + I ................. add to master
  SUPER + Ctrl + Return ..... swap with master

FOCUS  (arrows)
  SUPER + ←/→/↑/↓ ........... move focus

MOVE / SWAP WINDOW
  SUPER + Shift + ←/→/↑/↓ ... swap window in direction
  SUPER + Ctrl + ←/→/↑/↓ .... move window into group in direction

RESIZE
  SUPER + Shift + H/L ....... shrink / grow width
  SUPER + Shift + K/J ....... shrink / grow height

WORKSPACES
  SUPER + 1..0 .............. switch to workspace 1..10
  SUPER + Ctrl + 1..0 ....... move window to workspace (follow)
  SUPER + Shift + 1..0 ...... move window to workspace (silent)
  SUPER + . / , ............. next / previous workspace
  SUPER + Tab / Shift+Tab ... next / previous workspace
  SUPER + scroll ............ cycle workspaces

SCRATCHPAD
  SUPER + U ................. toggle special workspace
  SUPER + Shift + U ......... move window to scratchpad

MOUSE
  SUPER + Left-drag ......... move window
  SUPER + Right-drag ........ resize window

MEDIA / BRIGHTNESS  (function keys)
  XF86Audio* ................ volume / play / next / prev
  XF86MonBrightness* ........ brightness up / down

SCREENSHOTS
  Print .................... region screenshot → clipboard
  SUPER + Print ............ full screen → clipboard
